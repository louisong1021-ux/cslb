01 · L5 核心

不是“单打应该怎么打”，而是“这个人今天应该怎么打”

L4解决每一拍是否拥有战术许可；L5解决整场比赛如何围绕一个具体对手建立计划、验证计划、调整计划。

L5 = Scouting → 测试 → Match Plan A → 读取调整 → Plan B/C → 关键分执行 → 赛后验证
赛前假设

从录像或历史比赛中提出3–5个可验证的对手假设。

场上验证

前6分不是盲目抢分，而是用低风险球路确认哪些假设真实存在。

分层计划

Plan A是主战术，Plan B处理对手第一次调整，Plan C处理自己状态或环境变化。

证据更新

每次调整必须由比赛证据触发，不因一两个偶然失误推翻整个计划。

02 · Scouting Report

把对手档案压缩成比赛当天真正能用的6项信息

项目要确认比赛用途
后场两侧到位时间、击球点、默认线路、回中速度决定主要压迫侧与第二拍方向
前场两侧低点处理、回放/挑球/推球偏好决定网前控制与推后触发
身体/中路高速来球时正反手转换与防守质量打断提前保护四角
节奏偏好喜欢快节奏还是慢节奏，连续变速后是否失误决定是否抢时间或拖长回合
体能退化第几拍、哪一局开始恢复和球质下降决定什么时候拉长、什么时候提速
关键分选择17分后是否明显收缩到安全直线/高远/保守接发用于19分以后预测默认答案
最终报告不要超过一页。能记住并执行，比收集20条没有优先级的信息更重要。
03 · 前6分测试脚本

用低风险测试，快速确认对手模型

前6分不等于放弃得分，而是每一分除了得分目标，还承担一个信息目标。

测试目的要观察
深压反手后场确认压力默认直线高远/斜线/吊球比例与回中速度
高质量网前确认低点处理回放、挑直线、挑斜线、推球谁最常出现
连续两拍同侧确认保护动作基本点是否开始提前偏移
突然身体球打断四角预判正反手转换是否明显犹豫
快—慢节奏切换确认节奏适应第二次启动和击球点是否下降
一段长回合观察恢复质量回中速度、呼吸节奏、主动球质量是否改变
04 · Match Plan A/B/C

一场职业比赛至少准备三层方案

Plan A｜主战术

建立在赛前最有把握的弱点与自己的A级结构上，目标是尽快让比赛进入熟悉模式。

Plan B｜对手解决A

当对手提前保护、改变基本点或提高某条线路质量时，攻击保护动作制造的新空间。

Plan C｜自己或环境变化

如果自己后场质量下降、体能下降、风向/球速不利，改用更稳定、更低成本的得分结构。

停止条件

连续出现“球质不足却仍执行高风险战术”时，必须回到长度与基本点重建。

A有效 → 继续压；A被保护 → 进B；自己执行质量下降 → 进C；信息不足 → 回中性结构重新采样。
05 · 发接发专项计划

发接发必须和第三、第五拍绑定

场景第一目的第二层
高远发球建立长度、观察后场默认根据对手回球质量决定继续深压还是抢前场
短发压低接发、缩短对手时间准备回放、推后和身体平推三类答案
偷后场惩罚明显前压抓其后退失衡后的直线/中路默认球
接短发先拿高点回放、推后、推身体必须从相近准备动作出现
赛前就确定：关键分最信任的两种发球和两种接发是什么，避免19分以后临时发明。
06 · 环境与场地修正

风、球速、灯光和场地条件会改变最优战术

顺风/快球

后场更容易出界，降低无必要的大力高远风险；更重视压时间、点杀和控深度。

逆风/慢球

需要更完整的后场长度；直接杀死更困难，可增加构建型进攻和耐心。

灯光/背景

高球视觉不稳定时，减少自己不熟悉的高风险落点，先建立稳定击球节奏。

换边

换边后不要机械复制上一半局；重新评估长度、网前速度与对手最舒服的出球方向。

07 · 11分间歇调整

60秒内只解决最重要的三个问题

确认什么有效？对手怎么调整？下半局只改哪1–2件事？
  1. 保留：已经反复制造优势的模式，不因一次失误放弃。
  2. 删除：执行质量不足、持续让自己进入C/D级局面的选择。
  3. 更新：对手是否已经改变基本点、节奏、关键线路或体能状态。
  4. 关键分预案：如果打到17平以后，今天最可靠的两套模式是什么。
间歇不是重新设计整场比赛，而是缩小选择、提高执行清晰度。
08 · 决胜局工程

第三局不是“更拼”，而是把体能和风险重新定价

状态策略变化
自己体能更好提高回合长度，重复压恢复慢的一侧，让对手每分成本上升。
对手体能更好避免无意义长回合，争取更早拿高点和时间优势。
自己后场质量下降减少勉强进攻，优先恢复长度、基本点与稳定球质。
对手关键分收缩提前准备其安全默认答案，不要被表面“保守球”降低警觉。
09 · 场边记录模板

只记能改变下一分选择的信息

字段例子
稳定得分结构深反手 → 回直线高远 → 正手平高反方向
对手保护变化第10分后基本点开始偏反手，正手前场暴露
关键分默认17分后接短发更常回放直线
自己的执行限制逆风侧后场斜线长度不足，减少高风险交叉
Plan B触发连续两次提前站后保护 → 改前场
不要写“今天状态不好”这种无法执行的信息；要写“后场长度下降，所以下一阶段减少强行斜线进攻”。
10 · 赛后验证

判断计划错了，还是执行错了

模型正确 + 执行正确

保留为未来对该类型对手的高信心模式。

模型正确 + 执行失败

问题在技术质量、移动或体能，不应错误删除战术。

模型错误 + 执行正确

更新Player Profile，修正对手默认答案和保护方式。

模型错误 + 执行失败

拆开复盘，不要用一个结论解释全部失分。

L5完成标准：比赛前有计划，比赛中有触发条件，比赛后能证明为什么改、为什么不改。
