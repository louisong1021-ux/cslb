L1 · 基础结构

先建立“长度 + 基本点 + 恢复”的单打骨架

L1不追求复杂套路。目标是让每一拍都能把自己带回一个可继续比赛的位置。

单打基础 = 出球质量 → 恢复一步 → 相对基本点 → 对手触球前分腿 → 下一次启动
长度

高远、平高、被动挑球先做到足够深，避免对手长期高点击球。

基本点

不是回几何中心，而是根据上一拍落点和质量动态调整。

网前

先保证过网低和自己能恢复，再追求极致贴网。

进攻

杀球的第一价值是制造更简单的下一拍，而不是每次直接得分。

典型错误

错误真正问题修正
每拍机械回中忽略上一拍质量按对手击球位置调整相对基本点
后场不深却前压高估自己上一拍球不够深时基本点更保守
杀完停原地没有下一拍意识杀完立刻恢复并读取回球高度
L2 · 中高级构建

从“打四角”升级到“建立压力以后再变”

中高级单打开始利用重复、速度、落点和节奏制造重心偏置。

触发条件 → 建立压力 → 读取回中 → 第二层变化 → 保持主动
后场压力

深度稳定后用平高、重复同侧、身体球压缩启动时间。

前场压力

网前不是只求贴网，而是让对手低点处理并暴露身后。

节奏管理

快球后慢一拍，慢球后突然压时间，破坏对手启动周期。

动作一致性

高远、吊、劈吊、点杀准备动作尽量晚暴露。

先用重复制造预期，再攻击对手为了保护这个预期而让出的空间。
L3 · 高级比赛阅读

不只看空档，而是建模对手压力下的默认答案

真正稳定的战术不是猜一拍，而是让对手的选择越来越少。

对手模型

记录后场两侧、前场两侧、身体位、疲劳和关键分的默认处理。

回合架构

深度建立 → 压时间 → 读回中 → 反方向 → 抓短球。

诱导/反诱导

既要看自己在制造什么预期，也要看对手是否故意让你形成预期。

关键分

优先调用本场已验证的稳定模式，不临时发明高风险打法。

高级识别顺序

对手到位时间 → 击球点 → 身体姿态 → 第一恢复步 → 可能线路排序
L4 · 国际职业决策

判断“这一拍有没有资格执行那个战术”

空档存在，不代表你有资格去打。战术许可必须建立在真实球质上。

战术许可 = 深度/速度 × 击球点 × 对手失衡 × 自己恢复 × 下一拍覆盖
球质比赛含义允许做什么
A对手明显晚到、低点、失衡抢时间、前移基本点、准备终结
B有压力但仍有转换能力继续构建，不急着孤注一掷
C中性先争长度、节奏和高点
D自己晚到、低点、失衡先恢复球质和位置
技术质量不是战术的附属条件，而是战术本身的一部分。
L5 · 对手专项比赛工程

把所有能力用于“明天怎么打这个具体对手”

L5不是更多技术，而是赛前侦察、比赛测试、Plan A/B/C和局内验证。

Scouting

发接发、后场两侧、前场两侧、身体位、疲劳、关键分。

前6分测试

用低风险球验证对手是否真的存在某种压力下习惯。

Plan A/B/C

A主打法；B对手适应后的第二层；C自己状态差时的安全结构。

环境修正

风向、球速、灯光、场地视觉都会改变长度和风险边界。

赛前假设 → 前6分验证 → 11分校正 → 第二局升级 → 决胜局调用已验证模式
L6 · 高性能长期发展

从一场比赛升级到“这个运动员长期靠什么赢”

把技术、移动、体能、心理和长期数据接到同一个 Athlete Model。

Athlete Model

稳定得分模式、安全球、高风险球、弱区、压力下默认答案。

限制链

战术做不到时继续追：技术？第一步？制动？恢复？体能？

KPI

后场深度、主动转得分、被动恢复、中前场控制、关键分稳定性。

周期化

训练期、赛前、比赛周、连续比赛、恢复期的目标不同。

长期进步 = 发现限制 → 定向训练 → 比赛验证 → 数据确认 → 更新Athlete Model
