使用说明

  1. 进入网页后默认就是录入界面，不需要填写比赛基本信息。
  2. 每打一分，点击“添加一分记录”，按实际情况记录这一分；分数会根据得分方自动累计。
  3. “男生连续进攻拍数”只在男生形成连续下压进攻时填写，没有形成进攻填 0。
  4. “女生防守成功”建议仅在对手实际攻击女生时判断；没发生可选“不适用”。
  5. “女生封网成功”和“防守转攻成功”同样支持“不适用”，这样统计率的分母会更准确。
  6. 完成后点击“查看统计结果”，网页会自动生成关键指标、得失分结构和训练优先级。
  7. 数据自动保存在本机浏览器。可以导出 JSON 备份，也可从 JSON 导入恢复。
